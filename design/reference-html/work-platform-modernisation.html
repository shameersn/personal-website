CASE STUDY · WORKFORCE PLATFORM · 2023–2025

Modernising a platform with 700+ APIs

I led a team of 20 on a large, existing platform. We released version 2.0 of its web portals and mobile app, cleaned up the backend, and set up the data layer to handle more load.

CLIENT
Workforce platform
MY ROLE
Software architect, team lead
TEAM
20 people
STACK
React, React Native, Node.js, Spark

01 · THE PROBLEM

A big system with years of technical debt

The platform had six web portals, a mobile app and one large Node.js backend with more than 700 APIs. It had grown over years, and the technical debt made every new feature slower to build.

The team had to keep shipping features while fixing the foundations underneath.

02 · WHAT I DID

Fix the foundations while still shipping

  • Released version 2.0 of six React web portals and the React Native app, fixing technical debt along the way.
  • Optimised the Node.js monolith and its 700+ APIs.
  • Set up and clustered Cassandra, Kafka, MongoDB and Elasticsearch so the system could take more load.
  • Supported the Spark upgrade from version 2 to 3. Spark runs the heavy data processing and the core matching logic.
  • Guided the team on more than 15 third-party integrations, including Zoom, Stripe, Twilio, SES, OneSignal and Avalara.

03 · THE RESULT

A 2.0 release, and room to grow
